# CineSphere & Tokyo Sakura 3D

A collection of modern, responsive, and interactive web experiences built with semantic HTML5, CSS3, and Three.js.

## 🎬 Projects Included

### 1. CineSphere - Premium Cinema Web Application
A full-featured cinema ticketing and movie showcase platform:
- **Hero Spotlight Carousel**: Dynamic blockbuster banners, high-resolution backdrop switching, ratings, format badges, and official trailer modals.
- **Filterable Movie Catalog**: Live real-time search, genre filters, and 7-day dynamic showtime date picker.
- **Interactive Seat Reservation System**: Curved screen indicator with ambient glow, realistic seat states, and tiered pricing (Standard $12.50, Premium $16.00, VIP Recliners $22.00).
- **Concessions Add-on**: Integrated pre-ordering for gourmet popcorn, artisan nachos, craft sodas, and churros.
- **Digital E-Ticket Pass**: Boarding-pass styled ticket with perforation notches, auditorium details, seat numbers, concessions summary, and print/PDF support.
- **Cinema Experience Showcases**: Highlights for IMAX with Laser, Dolby Atmos 360° sound, 4DX motion seats, and VIP dining lounges.

### 2. Tokyo Sakura 3D (Three.js)
A 3D interactive cherry blossom environment set along the Meguro River overlooking the Tokyo skyline:
- **Procedural Blooming Sakura Tree**: Organic trunk and boughs, 3,800+ cherry blossom flowers with gradient petal shading, and illuminated paper lanterns (*chōchin*) with flickering amber light.
- **Tokyo Cityscape**: Detailed 3D model of Tokyo Tower with glowing lattice structure and pulsing beacon, 40+ skyscraper silhouettes with illuminated window grids, traditional vermilion arched bridge (*Taiko-bashi*), and stone garden lantern (*tōrō*).
- **Falling Petals Particle Simulation**: Over 2,500 individual 3D petals with fluttering wobble physics, tumbling rotation, and interactive mouse wind deflection.
- **Time of Day Presets**:
  - 🌙 **Yozakura (Night Bloom)**: Illuminated night blossoms with radiant bloom and glowing Tokyo Tower.
  - 🌅 **Twilight Sunset**: Magenta-gold sunset over the Tokyo skyline.
  - ☀️ **Spring Day**: Bright morning sunlight with crisp reflections.
- **Zen Sound Synthesizer**: Built-in Japanese *In-sen* pentatonic scale wind chime generator and breeze noise using Web Audio API.
- **Cinematic Tour**: Smooth automated drone flight path circling the tree and framing Tokyo Tower across the water.

## 🚀 Getting Started

No build tools, Node.js, or complex setups are required. Simply clone and open directly in any modern browser:

- Open **`index.html`** for the Cinema Website.
- Open **`sakura.html`** for the 3D Tokyo Sakura experience.
